# Claude Code — REF-RFX Agent

Read [`INSTRUCTIONS.md`](./INSTRUCTIONS.md) before taking any action in this repository.

Skills are available as slash commands in `.claude/skills/`. Type `/` in Claude Code to see available commands.

Skills are backlog-aware — invoke a skill without arguments to work on the current active item, or pass an explicit item number to target a specific item (e.g. `/deliberate item-03`).
